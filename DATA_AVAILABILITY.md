# Data availability

This repository currently releases the evaluation toolkit only. The SciFigBench
benchmark dataset is undergoing second-pass validation. Benchmark statistics,
annotations and benchmark results are not final.

The examples use one original synthetic flow diagram and synthetic QA/prediction
files. They are marked synthetic-v1 and use SYN identifiers. They are intended
for software checks and cannot support claims about benchmark/model performance.

No official benchmark figures, QA, content/structural annotations, private
validation material or actual model predictions are included in this release.

The existing SciFigBench repository is managed separately; publishing this
toolkit does not change that repository or its history.

After validation, data access instructions will be added here. Hugging Face is
the intended distribution channel. A future release will identify the exact
dataset revision, counts, checksums and data card. No release date is committed.

Toolkit version 0.2.0, report schema version 1.1 and dataset versions are independent.
Unversioned user QA receives dataset_version=unspecified in reports.
